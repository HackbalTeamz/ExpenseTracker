
# Expense Tracker website

This folder contains the complete static website: a homepage, privacy policy, support page, and shared stylesheet. It can be hosted on GitHub Pages or any static web host. It does not depend on a framework, build step, or third-party fonts.

## Before publishing

Replace `REPLACE_WITH_SUPPORT_EMAIL` in `privacy-policy.html` and `support.html` with a monitored support email. Check the policy against the app's actual behavior before submitting it to an app store.

## Publish with GitHub Pages

1. Push the repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Select **Deploy from a branch**, choose the `main` branch and `/docs` folder, then save.
4. GitHub will show the public website URL on the Pages settings screen. The privacy policy will be at `<website-url>/privacy-policy.html`.
